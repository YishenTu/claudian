# DeepSeek Harness constraints

- Preserve the user's existing native Web profile, credentials, model defaults and MCP configuration. Presets are invocation overlays; do not provision a Claudian profile or reconstruct native configuration. The two bundled plugins stay narrow: compatibility (literal per-preset prompt files and native auxiliary tool restrictions) and lifecycle (exit when Claudian's end of stdin closes). Harness owns tool execution, permissions and persistence.
- One workspace-owned `DeepSeekHost` runs a single native process for every DeepSeek session and history read. Only it starts, reconnects or stops the process; sessions attach through leases. `DeepSeekRoster` is the only subscriber to process-global streams and routes interactions to the nearest claimed subagent ancestor; forks name their source as native parent but are independent roots. A native session has at most one claimant per Host.
- Native exposes no close-session RPC: touched sessions keep their writers until the process stops. A second process claiming one gets `session/writer-held`; never remove native locks to make a read or resume succeed. Read cold history through projections and fixed-cut pages, and pre-session skill catalogs through `skills/list`; following a cold child or calling `commands/list` activates it.
- Prompt text changes go through preset prompt files and apply on the next native turn; they never restart the process. CLI or environment changes go through provider transitions. Releasing a session stops its owned native work; unconfirmed work ends with the process, never by restarting a Host other sessions use. A Host loss fails every attached session recoverably without stopping work, since retirement ends the process.
- Preserve the saved native store and preset across resume/forks. Code-mode preference changes affect new bindings. Auxiliary tool policy stays fixed for the lifetime of its Agent.
- Native streams have independent ordering and coalescing. Correlate requested turns with the prompt request ID, rebaseline owned jobs at turn completion, and use native child catalog modes. Unknown state remains busy until reconciliation or bounded failure disposal.
- Core output is append-only. Divergent streamed attempts require invalidation and reload guidance; cold hydration must still recover committed messages after failed attempts. Native Web persistence is required, so auxiliary discard releases its claim without deleting native transcripts.
